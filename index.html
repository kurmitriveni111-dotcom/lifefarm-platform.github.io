08 / CONTENT STUDIO

The Content Studio prepares publication files. It does not directly change the public website or grant publishing access. Only a person with permission to edit the GitHub repository can publish the exported content.

HOW PUBLISHING WORKS

  1. Open LIFEFARM Content Studio.
  2. Load the current content/articles.json.
  3. Create or edit an article and add a cover image path if needed.
  4. Download the updated JSON file.
  5. Replace content/articles.json in GitHub and commit the change.
  6. The public site updates automatically after deployment.

CONTENT RULES

  • Use original material or content you have permission to share.
  • Do not upload private personal information.
  • Use clear titles, dates, categories and summaries.
  • Keep images in assets/uploads/ and use relative paths.
  • Review the page on mobile after publishing.

11 / HELP CENTRE

How do I publish an article?

Open the Content Studio, load the current articles.json, create or edit your article, download the updated file, then replace content/articles.json in GitHub and commit.

How do I publish images?

Upload image files to assets/uploads in GitHub. Add their relative paths to the gallery using the Content Studio and export gallery.json. Replace content/gallery.json in GitHub and commit.

Is the participation card an official Member Key?

No. It is generated locally in your browser for display only. It is not a centrally registered account, secure credential or proof of membership.

Does this edition have member login or private storage?

No. This simple edition is static. It does not create accounts, store private member files or synchronize user information across devices.

How do I back up the website?

Use GitHub commit history and download a repository ZIP. Local browser data can be exported separately from the Local Backup tool.

Who can publish?

Only people who have permission to edit the GitHub repository can publish changes. The Content Studio itself does not grant access or upload changes.
