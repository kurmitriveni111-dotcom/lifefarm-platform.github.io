Content Studio

This editor runs in your browser. It does not log in to GitHub, publish directly or protect content with a password. Only repository collaborators can publish by uploading the exported JSON file to GitHub.

1 · Load current publications

Load the existing content/articles.json file before editing so you do not accidentally overwrite previous articles.

2 · Create or edit an article

3 · Export and publish

Download the updated JSON file, then replace content/articles.json in your GitHub repository. Commit the change to publish.

Images: upload the image separately to assets/uploads/ in GitHub. Then use its relative path in the cover image field. Do not paste private documents or sensitive data here.

4 · Manage gallery entries

Load the current content/gallery.json, add image paths, then export the updated file. Upload each image separately to assets/uploads/.
